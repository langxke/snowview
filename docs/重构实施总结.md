# AI 多会话重构实施总结

## 实施时间
2025年10月25日

## 背景

原有的 `AIProvider` 存在以下问题：
1. 代码超过 1600 行，单一类职责过重
2. 切换会话时强制停止 AI 生成，导致内容丢失
3. 无法支持多会话并发生成
4. 工具调用逻辑与会话管理耦合，难以维护

## 实施内容

### 1. 创建 AIToolCallOrchestrator（工具调用编排器）
**文件**: `lib/presentation/providers/ai_tool_call_orchestrator.dart` (713 行)

**职责**:
- 管理工具调用的完整流程（解析、执行、递归）
- 控制递归深度，防止无限循环（最大10层）
- 获取 AI 的最终回复
- 处理工具调用相关的错误

**核心方法**:
```dart
Future<ToolCallResult> handleToolCalls({
  required List<OpenAIToolCall> toolCalls,
  required String sessionId,
  required List<ChatMessageHive> conversationHistory,
  required Future<void> Function(ChatMessageHive) onMessageGenerated,
})
```

**结果类型**:
- `ToolCallResult`: 表示工具调用的最终结果（成功/停止/错误）
- `ToolExecutionResult`: 表示单个工具的执行结果
- `FinalResponseResult`: 表示 AI 最终回复的结果

### 2. 创建 AISession（会话管理器）
**文件**: `lib/presentation/providers/ai_session.dart` (~450 行)

**职责**:
- 管理单个会话的消息列表
- 处理流式生成
- 委托工具调用给编排器
- 维护会话状态（是否正在思考、错误信息等）

**核心属性**:
```dart
class AISession {
  List<ChatMessageHive> messages = [];
  bool isThinking = false;
  String? errorMessage;
  StreamSubscription? _streamSubscription;
  bool _shouldStop = false;
}
```

**核心方法**:
- `sendMessage()`: 发送用户消息，启动流式生成
- `stop()`: 停止当前会话的生成
- `loadHistory()`: 从数据库加载历史消息

### 3. 重构 AIProvider（会话调度器）
**文件**: `lib/presentation/providers/ai_provider.dart` (424 行, 减少 74%)

**职责**:
- 管理多个 `AISession` 实例
- 处理会话切换（不中断生成）
- 协调全局状态（AI 模式、并发控制）
- 通知 UI 更新

**核心改进**:

## 技术亮点

### 1. 状态隔离
每个会话独立维护自己的状态，互不干扰：
```dart
class AISession {
  // 每个会话独立的消息列表
  List<ChatMessageHive> messages = [];
  
  // 每个会话独立的生成状态
  bool isThinking = false;
  
  // 每个会话独立的 Stream 订阅
  StreamSubscription? _streamSubscription;
}
```

### 2. 回调模式
使用回调函数通知状态变化，避免紧耦合：
```dart
AISession(
  onStateChanged: () {
    // 当会话状态变化时，如果是当前会话，通知 UI 更新
    if (_currentSessionId == sessionId && !_disposed) {
      _safeNotifyListeners();
    }
  },
)
```

### 3. 委托模式
工具调用通过回调生成消息，解耦会话与工具逻辑：
```dart
await _toolOrchestrator.handleToolCalls(
  toolCalls: toolCalls,
  sessionId: sessionId,
  conversationHistory: messages,
  onMessageGenerated: (message) async {
    // 工具编排器生成新消息时的回调
    messages.add(message);
    await _historyRepo.saveMessage(message);
    _notifyChanged();
  },
);
```

### 4. 结果封装
使用专门的结果类表达不同的执行状态：
```dart
class ToolCallResult {
  final ToolCallStatus status; // success, stopped, error
  final ChatMessageHive? message;
  final int executedToolsCount;
  final String? errorMessage;
}
```
