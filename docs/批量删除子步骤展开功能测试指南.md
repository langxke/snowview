# 批量删除子步骤展开功能测试指南

## 🎯 测试目标

验证批量删除子步骤后，点击展开按钮能够显示已删除的子步骤标题。

---

## 📋 前置准备

### 1. 准备测试数据

需要一个包含多个子步骤的任务，例如：
- 任务：完成项目文档
  - 子步骤1：编写需求文档
  - 子步骤2：编写设计文档
  - 子步骤3：编写API文档

可以通过以下方式创建：
- 手动在任务列表中添加
- 或者让 AI 帮你创建："帮我创建一个任务'完成项目文档'，包含3个子步骤：编写需求文档、编写设计文档、编写API文档"

---

## 🧪 测试步骤

### 测试场景 1：删除单个任务的所有子步骤

1. **启动应用**
   ```bash
   flutter run -d windows
   ```

2. **执行删除操作**
   
   在 AI 对话框中输入：
   ```
   帮我删除"完成项目文档"任务下的所有子步骤
   ```

3. **观察 AI 工具调用组件**
   
   应该看到：
   - ✅ 显示一个工具调用卡片
   - ✅ 卡片右侧有展开按钮（向下箭头 ▼）
   - ✅ 卡片显示类似："批量删除子步骤 (任务ID: xxx, 3个子步骤)"

4. **点击展开按钮**
   
   展开后应该显示：
   - ✅ **编写需求文档**
   - ✅ **编写设计文档**
   - ✅ **编写API文档**
   
   **❌ 不应该显示**：
   - ❌ "子步骤 1"
   - ❌ "子步骤 2"
   - ❌ "子步骤 3"

5. **检查控制台日志**
   
   应该能看到以下调试输出：

   **执行阶段：**
   ```
   [Tool Orchestrator] 🔧 执行: batch_delete_subtasks
   [Tool Orchestrator] 📝 参数: {taskId: xxx, subtaskIds: [id1, id2, id3]}
   [Tool Orchestrator] ✅ 执行结果: batch_delete_subtasks
   [Tool Orchestrator] 📊 返回数据: {success: true, totalCount: 3, successCount: 3, failureCount: 0, message: ..., taskTitle: 完成项目文档, deletedSubtasks: [编写需求文档, 编写设计文档, 编写API文档]}
   ```

   **保存阶段：**
   ```
   [Tool Orchestrator] 🔍 保存的 resultsMap: {call_xxx: {success: true, ..., deletedSubtasks: [编写需求文档, 编写设计文档, 编写API文档]}}
   [Tool Orchestrator] 🔍 toolResults JSON: {"call_xxx":{"success":true,...}}
   [Tool Orchestrator] 💾 已保存工具执行结果到消息
   ```

   **UI 渲染阶段：**
   ```
   [AIToolCallWidget] 🔍 批量删除子步骤 - toolCallId: call_xxx
   [AIToolCallWidget] 🔍 allResults keys: [call_xxx]
   [AIToolCallWidget] 🔍 result: {success: true, ..., deletedSubtasks: [编写需求文档, 编写设计文档, 编写API文档]}
   [AIToolCallWidget] 🔍 deletedSubtasks: [编写需求文档, 编写设计文档, 编写API文档]
   ```

## 🔧 问题排查

### 问题 1: 展开后没有内容

**可能原因**：
- 这是旧的聊天记录（在修复之前生成的）

**解决方法**：
- 删除旧的聊天记录，创建新的对话
- 或者创建一个新任务重新测试

**检查方法**：
- 查看控制台，如果没有 `[AIToolCallWidget] 🔍` 开头的调试日志，说明是旧数据

---

### 问题 2: 显示的是 "子步骤 1"、"子步骤 2"

**可能原因**：
- `toolResults` 为 null 或解析失败
- 回退到了旧的兼容逻辑

**解决方法**：
1. 检查控制台是否有以下日志：
   ```
   [AIToolCallWidget] 🔍 result: null
   ```
   如果是 null，说明结果没有正确保存

2. 检查是否有以下日志：
   ```
   [Tool Orchestrator] 💾 已保存工具执行结果到消息
   ```
   如果没有这条日志，说明保存逻辑没有执行

3. 检查 Hive 数据库是否正确更新

---

### 问题 3: 控制台报错

**可能的错误**：
```
[AIToolCallWidget] ⚠️ 解析 toolResults 失败: ...
```

**解决方法**：
- 检查 `toolResults` 的 JSON 格式是否正确
- 查看完整的错误信息，定位解析失败的原因

---

## ✅ 成功标准

测试通过的标准：
1. ✅ 点击展开按钮后，能看到具体的子步骤标题
2. ✅ 子步骤标题与实际删除的子步骤一致
3. ✅ 控制台没有错误日志
4. ✅ 控制台能看到完整的调试日志链路
