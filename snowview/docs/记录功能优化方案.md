# 记录功能优化方案

## 📋 文档信息

**优化版本**：v1.1  
**创建日期**：2025年10月8日  
**优化目标**：简化功能、提升用户体验  

---

## 1. 优化需求概述

### 当前问题
1. ❌ 类别固定（日记/周记/随笔），用户无法自定义
2. ❌ 标签功能过早引入，增加复杂度
3. ❌ 编辑器是小对话框，不适合长文本阅读
4. ❌ 新建时需要选择类型，操作繁琐

### 优化目标
1. ✅ 类别可自定义（类似任务类别系统）
2. ✅ 暂时移除标签功能（保留数据字段，UI不显示）
3. ✅ 全屏编辑/预览体验
4. ✅ 简化新建流程（根据当前选中类别直接创建）

---

## 8. 详细实施方案

### 8.1 三栏布局实现

**JournalScreen 结构**：
```dart
class JournalScreen extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Consumer<JournalProvider>(
      builder: (context, provider, child) {
        final selectedEntry = provider.selectedEntry;  // 新增选中状态
        
        return Row(
          children: [
            // 左：类别栏（200px）
            JournalCategorySidebar(
              categories: provider.categories,
              selectedCategoryId: provider.selectedCategoryId,
              onCategorySelected: provider.selectCategory,
              onCreateCategory: _createCategory,
            ),
            
            const VerticalDivider(width: 1),
            
            // 中：记录列表（自适应）
            Expanded(
              child: JournalListPanel(
                entries: provider.entries,
                selectedEntryId: provider.selectedEntryId,
                onEntryTap: provider.selectEntry,
                onCreateEntry: () => _createEntry(provider.selectedCategoryId),
              ),
            ),
            
            // 右：详情面板（450px，条件显示）
            if (selectedEntry != null) ...[
              const VerticalDivider(width: 1),
              SizedBox(
                width: 450,
                child: JournalDetailPanel(
                  entry: selectedEntry,
                  onClose: () => provider.selectEntry(null),
                  onUpdate: provider.updateEntry,
                  onDelete: () => _deleteEntry(selectedEntry.id),
                ),
              ),
            ],
          ],
        );
      },
    );
  }
}
```

## 9. 向后兼容方案

### 旧数据迁移

```dart
Future<void> _migrateOldData() async {
  final entries = _repository.getAllEntries();
  
  for (final entry in entries) {
    // 如果有旧的 type 字段，但没有 categoryId
    if (entry.categoryId.isEmpty && entry.legacyType != null) {
      String categoryId;
      switch (entry.legacyType) {
        case 'diary':
          categoryId = 'daily';
          break;
        case 'weekly':
          categoryId = 'weekly';
          break;
        case 'note':
          categoryId = 'note';
          break;
        default:
          categoryId = 'note';
      }
      
      final updated = entry.copyWith(categoryId: categoryId);
      await _repository.updateEntry(updated);
    }
  }
}
```
