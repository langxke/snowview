## 🎯 设计理念

### 功能分工

| 功能 | 工作会话 | 专注功能（番茄钟） |
|------|---------|-------------------|
| **定位** | ⏰ 时间规划工具 | ⏱️ 时间追踪工具 |
| **场景** | "我计划明天下午2点做这个任务" | "我现在开始做任务，计时25分钟" |
| **关键功能** | 创建、编辑、删除时间安排 | 开始、暂停、继续、完成计时 |
| **数据记录** | 计划时间、关联任务/子步骤 | 实际开始/结束时间、实际时长 |
| **UI位置** | 任务详情、日历视图 | 独立的专注页面/浮窗 |

### 工作流程
```
1. 用户在任务详情创建工作会话（时间规划）
           ↓
2. 日历中显示这些会话
           ↓
3. 到了时间，用户点击"开始专注"
           ↓
4. 进入专注功能（番茄钟）进行实际工作
           ↓
5. 专注完成后，工作会话自动标记为"已完成"
           ↓
6. 实际时长从专注会话获取
```
