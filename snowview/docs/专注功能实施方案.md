## 1. 功能概述

### 核心功能
- 🍅 番茄钟计时器（25分钟工作 + 5分钟休息）
- ⏱️ 自定义时长专注
- 📊 每日专注统计
- 🔗 关联任务/工作会话
- 🔔 完成通知提醒
- 🎵 音效支持（可选）

### 使用场景
1. **独立专注**：不关联任务，单纯计时
2. **任务专注**：关联具体任务，自动累计任务时长
3. **会话专注**：关联工作会话，完成后更新会话状态

## 2. 数据模型设计

### 2.1 FocusSessionHive（专注会话）
**TypeId**: 5

```dart
@HiveType(typeId: 5)
class FocusSessionHive extends HiveObject {
  @HiveField(0) String id;
  @HiveField(1) String? taskId;              // 关联任务ID
  @HiveField(2) String? workSessionId;       // 关联工作会话ID

  @HiveField(7) DateTime startTime;
  @HiveField(8) DateTime? endTime;
  @HiveField(9) String? note;
  @HiveField(10) bool isBreak;               // 是否为休息
  @HiveField(11) List<DateTime> pauseTimestamps;
  @HiveField(12) DateTime createdAt;
  
  // 计算属性
  int get remainingSeconds;
  bool get isCompleted;

}
```

## 9. 技术要点

### 9.1 计时器处理
```dart
// 后台时间累加
@override
void didChangeAppLifecycleState(AppLifecycleState state) {
  if (state == AppLifecycleState.paused && _currentSession != null) {
    _backgroundTime = DateTime.now();
  } else if (state == AppLifecycleState.resumed && _backgroundTime != null) {
    final inBackgroundSeconds = DateTime.now().difference(_backgroundTime!).inSeconds;
    _elapsedSeconds += inBackgroundSeconds;
    notifyListeners();
  }
}
```

### 9.2 与现有系统集成
```dart
// 专注完成后更新工作会话
Future<void> _updateWorkSession() async {
  if (_currentSession?.workSessionId != null) {
    final workSession = await _workSessionRepo.getSessionById(_currentSession!.workSessionId!);
    if (workSession != null) {
      await _workSessionRepo.updateSession(workSession.copyWith(status: 'completed'));
    }
  }
}
```
