## 📊 核心数据流

### 1. 创建工作会话流程
```
用户操作 → TaskDetailPanel → WorkSessionDialog
    ↓
选择时间/子步骤/备注
    ↓
TaskListProvider.createWorkSession()
    ↓
WorkSessionRepository.saveSession()
    ↓
Hive 数据库持久化
    ↓
UI 自动刷新
```

### 2. 日历显示流程
```
日历视图 → ScheduleProvider.getTimeBlocksForDate()
    ↓
获取日历事件 (CalendarEventHive)
    ↓
获取任务会话 (WorkSessionHive)
    ↓
关联任务和类别数据
    ↓
转换为 TimeBlock 统一模型
    ↓
按时间排序并返回
    ↓
日历视图渲染（显示任务名称和类别颜色）
```

### 3. 级联删除流程
```
删除任务 → TaskListProvider.deleteTask()
    ↓
WorkSessionRepository.deleteSessionsByTaskId()
    ↓
删除所有关联会话
    ↓
TaskListRepository.deleteTask()
    ↓
删除任务本身
```
