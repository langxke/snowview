## 1. 功能概述

### 核心需求
**"新建对话时在顶部出现横向的对话窗口选择栏，支持横向滚动"**

**核心价值**：
- 🗂️ 管理多个独立的AI对话会话
- 🔄 快速切换不同对话主题
- 📂 每个会话独立的消息历史
- 🏷️ 自动或手动命名会话标题

## 5. 状态管理层实现

### 5.1 扩展 AIProvider

**文件**: `lib/presentation/providers/ai_provider.dart`

```dart
class AIProvider extends ChangeNotifier {
  final ChatSessionRepository _sessionRepo;  // 新增
  
  String? _currentSessionId;                 // 新增：当前会话ID
  List<ChatSessionHive> _sessions = [];      // 新增：所有会话列表
  
  // ==================== 新增Getters ====================
  
  String? get currentSessionId => _currentSessionId;
  List<ChatSessionHive> get sessions => _sessions;
  ChatSessionHive? get currentSession => 
      _currentSessionId != null ? _sessionRepo.getSession(_currentSessionId!) : null;
  
  // ==================== 会话管理 ====================
  
  /// 初始化 - 加载所有会话
  Future<void> _loadSessions() async {
    _sessions = _sessionRepo.getAllSessions();
    
    // 如果有会话，选中最新的；否则创建新会话
    if (_sessions.isNotEmpty) {
      _currentSessionId = _sessions.first.id;
      await _loadHistory();
    } else {
      await createNewSession();
    }
    notifyListeners();
  }
  
  /// 创建新会话
  Future<void> createNewSession() async {
    final id = const Uuid().v4();
    final session = await _sessionRepo.createSession(
      id: id,
      title: '新对话',
    );
    
    _sessions.insert(0, session);  // 插入到列表开头
    _currentSessionId = id;
    _messages.clear();
    _errorMessage = null;
    
    notifyListeners();
  }
  
  /// 切换会话
  Future<void> switchSession(String sessionId) async {
    if (_currentSessionId == sessionId) return;
    
    _currentSessionId = sessionId;
    await _loadHistory();  // 加载该会话的消息
    _errorMessage = null;
    
    notifyListeners();
  }
  
  /// 删除会话
  Future<void> deleteSession(String sessionId) async {
    // 删除会话
    await _sessionRepo.deleteSession(sessionId);
    
    // 删除该会话的所有消息
    await _historyRepo.deleteMessagesBySessionId(sessionId);
    
    // 从列表移除
    _sessions.removeWhere((s) => s.id == sessionId);
    
    // 如果删除的是当前会话，切换到其他会话
    if (_currentSessionId == sessionId) {
      if (_sessions.isNotEmpty) {
        await switchSession(_sessions.first.id);
      } else {
        await createNewSession();
      }
    }
    
    notifyListeners();
  }
  
  /// 重命名会话
  Future<void> renameSession(String sessionId, String newTitle) async {
    final session = _sessionRepo.getSession(sessionId);
    if (session != null) {
      session.updateTitle(newTitle);
      await _sessionRepo.updateSession(session);
      
      // 更新列表中的会话
      final index = _sessions.indexWhere((s) => s.id == sessionId);
      if (index != -1) {
        _sessions[index] = session;
      }
      
      notifyListeners();
    }
  }
  
  // ==================== 修改现有方法 ====================
  
  /// 加载历史消息 - 修改为加载当前会话的消息
  Future<void> _loadHistory() async {
    if (_currentSessionId == null) {
      _messages = [];
    } else {
      _messages = _historyRepo.getMessagesBySessionId(_currentSessionId!);
    }
    notifyListeners();
  }
  
  /// 发送消息 - 修改为关联当前会话
  Future<void> sendMessage(String content) async {
    // ... 现有逻辑
    
    // 创建消息时添加 sessionId
    final userMessage = ChatMessageHive.user(
      id: const Uuid().v4(),
      content: content,
      sessionId: _currentSessionId!,  // 新增
    );
    
    // ... 其余逻辑
    
    // 自动生成会话标题（如果是第一条消息）
    final session = currentSession;
    if (session != null && session.messageCount == 0) {
      // 使用用户的第一条消息作为标题（截取前20个字符）
      final title = content.length > 20 
          ? '${content.substring(0, 20)}...' 
          : content;
      await renameSession(_currentSessionId!, title);
    }
  }
  
  /// 清除历史 - 修改为只清除当前会话
  Future<void> clearHistory() async {
    if (_currentSessionId != null) {
      await deleteSession(_currentSessionId!);
    }
  }
}
```

    required this.currentSessionId,
    required this.onSessionSelected,
    required this.onNewSession,
    this.onDeleteSession,
  });
  
  @override
  Widget build(BuildContext context) {
    return Container(
      height: 60,
      decoration: BoxDecoration(
        color: Theme.of(context).colorScheme.surface,
        border: Border(
          bottom: BorderSide(
            color: Theme.of(context).colorScheme.outline.withOpacity(0.2),
          ),
        ),
      ),
      child: ListView.builder(
        scrollDirection: Axis.horizontal,  // 横向滚动
        padding: const EdgeInsets.symmetric(horizontal: 8, vertical: 8),
        itemCount: sessions.length + 1,  // +1 为新建按钮

          // 新建按钮

            return _buildNewSessionButton(context);
          }
          
          // 会话标签
          final session = sessions[index];
          final isActive = session.id == currentSessionId;
          
          return _buildSessionTab(context, session, isActive);
        },
      ),
    );
  }
  
  Widget _buildSessionTab(
    BuildContext context,
    ChatSessionHive session,
    bool isActive,

    return GestureDetector(
      onTap: () => onSessionSelected(session.id),
      onLongPress: () => _showSessionOptions(context, session),

        width: 140,

          color: isActive 
              ? colorScheme.primaryContainer 
              : colorScheme.surfaceVariant,
          borderRadius: BorderRadius.circular(8),
          border: Border.all(
            color: isActive 
                ? colorScheme.primary 
                : Colors.transparent,

          ),
        ),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          mainAxisAlignment: MainAxisAlignment.center,

              children: [
                Expanded(
                  child: Text(
                    session.title,

              style: TextStyle(
                color: (isActive 
                    ? colorScheme.onPrimaryContainer 
                    : colorScheme.onSurfaceVariant).withOpacity(0.7),
                fontSize: 11,
              ),
            ),
          ],
        ),
      ),
    );
  }

## 8. 技术注意事项

### 8.1 数据一致性

**问题**：删除会话时需要同时删除相关消息

**解决方案**：
```dart
Future<void> deleteSession(String sessionId) async {
  // 1. 先删除会话的所有消息
  await _historyRepo.deleteMessagesBySessionId(sessionId);
  
  // 2. 再删除会话本身
  await _sessionRepo.deleteSession(sessionId);
  
  // 3. 更新UI状态
  // ...
}
```

### 8.2 自动生成标题

**策略**：
1. 新建会话时默认标题为"新对话"
2. 发送第一条消息后，自动用消息内容生成标题
3. 截取前20个字符，超出添加省略号
4. 用户可以手动重命名

### 8.3 性能优化

**横向滚动优化**：
- 使用 `ListView.builder` 而不是 `ListView`
- 设置合理的 `itemExtent` 或固定宽度
- 避免在滚动时重建整个列表

### 8.4 数据迁移

**现有消息的处理**：

如果已有历史消息，需要迁移到默认会话：

```dart
Future<void> migrateExistingMessages() async {
  final messages = _historyRepo.getAllMessages();
  
  if (messages.isNotEmpty) {
    // 创建一个默认会话
    final defaultSession = await _sessionRepo.createSession(
      id: 'default',
      title: '历史对话',
    );
    
    // 将所有消息关联到该会话
    for (final message in messages) {
      message.sessionId = 'default';
      defaultSession.addMessageId(message.id);
      await message.save();
    }
    
    await _sessionRepo.updateSession(defaultSession);
  }
}
```

## 12. 风险和应对

### 风险1：数据迁移
**风险**：现有消息可能丢失  
**应对**：实现自动迁移逻辑，将现有消息归到默认会话

### 风险2：性能问题
**风险**：会话过多时滚动卡顿  
**应对**：使用 ListView.builder，限制会话数量（如最多保留50个）

### 风险3：用户体验
**风险**：用户不理解多会话概念  
**应对**：提供简单的引导提示，默认行为与单会话一致
