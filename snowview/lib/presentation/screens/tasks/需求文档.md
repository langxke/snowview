# 📋 清单功能需求分析（修订版）

## 一、功能概述

**两栏+浮层式任务管理系统**，采用"类别 → 列表 + 详情浮层"的结构，右侧详情面板仅在选中任务时显示。

---

## 🎯 核心需求拆解

### 1. 数据模型设计（简化版）

#### 1.1 类别（Category）
```dart
class TaskCategory {
  String id;                    // 唯一标识
  String name;                  // 类别名称（如：工作、学习、生活）
  Color color;                  // 主题色
  int order;                    // 排序序号
}
```

**说明：**
- 去掉了 `icon`：统一使用文件夹图标或颜色块标识
- 去掉了 `createdAt`：不需要追踪创建时间
- 保留 `color`：用于区分不同类别，视觉效果更好
- 保留 `order`：支持用户自定义排序

#### 1.2 任务（Task）
```dart
class Task {
  String id;                    // 唯一标识
  String title;                 // 标题
  String? description;          // 备注/描述
  String categoryId;            // 所属类别
  bool isCompleted;             // 是否完成
  DateTime? dueDate;            // 截止日期
  DateTime? remindAt;           // 提醒时间
  List<SubTask> subTasks;       // 子步骤列表
  DateTime createdAt;           // 创建时间
  DateTime? completedAt;        // 完成时间
  int order;                    // 排序序号
}
```

**说明：**
- 去掉了 `priority`：优先级通过类别来体现（工作类优先级高于生活类）
- 保留 `createdAt` 和 `completedAt`：用于排序和统计
- 保留其他核心字段

#### 1.3 子步骤（SubTask）
```dart
class SubTask {
  String id;                    // 唯一标识
  String title;                 // 步骤标题
  bool isCompleted;             // 是否完成
  int order;                    // 排序序号
}
```

#### 2.2 详情面板交互逻辑

**显示时机：**
- ✅ 点击任务列表中的任务标题 → 详情面板从右侧滑入
- ✅ 再次点击同一任务 → 详情面板关闭（或保持打开，取决于设计偏好）
- ✅ 点击其他任务 → 详情面板内容切换（平滑过渡）
- ✅ 点击详情面板外的区域 → 详情面板关闭（可选）
- ✅ 点击关闭按钮 → 详情面板滑出

**动画效果：**
- 从右侧滑入（300ms，Curves.easeOut）
- 滑出时反向动画
- 任务列表宽度平滑过渡（从100%缩减到适应剩余空间）

#### 2.3 响应式布局策略

- **宽屏（>1200px）：** 详情面板宽度350px，任务列表自适应
- **中屏（800-1200px）：** 详情面板覆盖式显示（Overlay），半透明背景
- **窄屏（<800px）：** 详情面板全屏显示，使用路由导航

### 3. 核心功能模块（简化版）

**核心功能：**
- ✅ 创建类别（仅名称 + 颜色）

- 不需要图标选择器
- 只需要颜色选择器（预设8-10种颜色）
- 创建对话框极简（名称输入框 + 颜色选择）

**显示逻辑：**
- ✅ 根据选中类别显示对应任务
- ✅ 按状态分组：
  - 未完成任务（顶部，默认展开）
  - 已完成任务（底部，默认折叠，可点击展开）

**显示内容：**
- Checkbox（完成状态）
- 任务标题（点击查看详情）
- 子步骤进度（如果有子步骤，显示"2/5"）
- 截止日期标签（如果有，显示相对时间："今天"、"明天"、"后天"、"MM/DD"）

**快速操作：**
- ✅ 勾选Checkbox → 切换完成状态（即时更新，带动画）
- ✅ 点击标题 → 打开详情面板
- ✅ 长按/右键 → 快捷菜单（删除、移动到其他类别）

- 列表底部固定输入框："+ 新建任务"
- 输入标题后按Enter → 创建任务（自动归类到当前类别）
- 创建后输入框清空，可连续添加

**面板结构（从上到下）：**

1. **头部区域**

| **提醒时间** | 提醒通知时间 | 点击打开日期时间选择器 |

**自动保存机制：**
- 所有字段修改后**自动保存**（防抖500ms）
- 无需"保存"按钮
- 保存成功后不显示提示（无感保存）
- 保存失败时显示Toast提示

String formatDueDate(DateTime? date) {
  if (date == null) return '';
  
  final now = DateTime.now();
  final today = DateTime(now.year, now.month, now.day);
  final tomorrow = today.add(Duration(days: 1));
  final dateOnly = DateTime(date.year, date.month, date.day);
  
  if (dateOnly == today) return '今天';
  if (dateOnly == tomorrow) return '明天';
  if (dateOnly.difference(today).inDays < 7) {
    return '${date.month}/${date.day}';
  }
  return '${date.month}月${date.day}日';
}

class TaskProvider with ChangeNotifier {
  String? _selectedTaskId;
  
  void selectTask(String? taskId) {
    _selectedTaskId = taskId;
    notifyListeners();
  }
  
  Task? get selectedTask {

  }
  
  bool get isDetailPanelVisible => _selectedTaskId != null;
}
