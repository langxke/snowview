### 2. Repository层（数据持久化）

##### 任务管理
- `saveTask(ChecklistTaskHive task)` - 保存任务
- `updateTask(ChecklistTaskHive task)` - 更新任务
- `deleteTask(String taskId)` - 删除任务
- `getAllTasks()` - 获取所有任务
- `getTasksByCategory(String categoryId)` - 根据类别获取任务
- `getTaskById(String id)` - 根据ID获取任务
- `getUncompletedTaskCount(String categoryId)` - 获取未完成任务数量
- `getTasksByDate(DateTime date)` - 根据日期获取任务

### 3. Hive数据库配置

已在 `main.dart` 中完成配置：

```dart
// 注册Hive适配器
Hive.registerAdapter(TaskCategoryHiveAdapter());
Hive.registerAdapter(SubTaskHiveAdapter());

await TaskListRepository.init();
```

**数据库Boxes：**
- `task_categories` - 存储任务类别
- `checklist_tasks` - 存储清单任务

### 4. Provider状态管理

#### 🎯 `TaskListProvider`
位置：`lib/presentation/providers/task_list_provider.dart`

**核心属性：**
- `categories` - 所有类别列表
- `tasks` - 所有任务列表
- `selectedCategoryId` - 当前选中的类别ID
- `selectedTaskId` - 当前选中的任务ID（控制详情面板显示）
- `selectedTask` - 当前选中的任务对象
- `currentTasks` - 当前显示的任务列表（根据类别筛选）
- `uncompletedTasks` - 未完成的任务
- `completedTasks` - 已完成的任务
- `isDetailPanelVisible` - 详情面板是否可见

**核心方法：**

##### 类别相关
- `selectCategory(String? categoryId)` - 选择类别
- `createCategory({name, color})` - 创建类别
- `updateCategory({id, name, color})` - 更新类别
- `deleteCategory(String id)` - 删除类别
- `getCategoryTaskCount(String categoryId)` - 获取类别任务数量

##### 任务相关
- `selectTask(String? taskId)` - 选择任务（打开详情面板）
- `createTask({title, categoryId})` - 创建任务
- `updateTask({id, title, description, dueDate, remindAt})` - 更新任务
- `toggleTaskCompletion(String taskId)` - 切换任务完成状态
- `deleteTask(String taskId)` - 删除任务

##### 子步骤相关
- `addSubTask(String taskId, String title)` - 添加子步骤
- `toggleSubTask(String taskId, String subTaskId)` - 切换子步骤状态
- `deleteSubTask(String taskId, String subTaskId)` - 删除子步骤

##### 日历集成
- `getTasksByDate(DateTime date)` - 根据日期获取任务

**默认功能：**
- 首次启动自动创建3个默认类别：工作（蓝色）、学习（绿色）、生活（橙色）
- 默认选中"全部"类别
- 数据自动加载和持久化

## 📝 使用说明

### 如何在其他页面访问TaskListProvider

```dart
import 'package:provider/provider.dart';
import 'package:snowview/presentation/providers/task_list_provider.dart';

// 在Widget中使用
class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final provider = context.watch<TaskListProvider>();
    
    // 获取任务列表
    final tasks = provider.currentTasks;
    
    // 创建任务
    provider.createTask(
      title: '新任务',
      categoryId: 'work',
    );
    
    return Container();
  }
}
```
