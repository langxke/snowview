### 1. 核心组件

#### 📦 `CategoryItem` - 单个类别条目组件
位置：`lib/presentation/screens/tasks/widgets/category_item.dart`

**功能特性：**
- ✅ 支持特殊类别（如"全部"）和用户类别
- ✅ 显示类别名称、图标/颜色、任务计数
- ✅ 选中状态高亮显示
- ✅ 用户类别支持编辑和删除（通过更多菜单）
- ✅ 支持长按显示底部菜单（移动端友好）

**两种工厂方法：**
```dart
// 创建特殊类别（如"全部"）
CategoryItem.special(
  id: 'all',
  name: '全部',
  icon: Icons.inbox,
  count: 10,
  isSelected: true,
  onTap: () {},
)

// 创建用户类别
CategoryItem.user(
  category: category,
  count: 5,
  isSelected: false,
  onTap: () {},
  onEdit: () {},
  onDelete: () {},
)
```

#### 📝 `CategoryDialog` - 创建/编辑类别对话框
位置：`lib/presentation/screens/tasks/dialogs/category_dialog.dart`

**功能特性：**
- ✅ 统一对话框同时支持创建和编辑
- ✅ 名称输入框（带图标和提示）
- ✅ 集成颜色选择器
- ✅ 编辑模式显示删除按钮
- ✅ 输入验证（名称不能为空）
- ✅ 删除前显示二次确认

**使用方法：**
```dart
// 创建类别
final result = await CategoryDialog.showCreate(context);

// 编辑类别
final result = await CategoryDialog.showEdit(context, category, onDeleted);

// 处理结果
if (result != null) {
  print('名称: ${result.name}');
  print('颜色: ${result.color}');
  print('操作: ${result.action}');
}
```

### 2. 业务逻辑实现

#### ✅ 创建类别
- 打开创建对话框
- 输入名称、选择颜色
- 点击"创建"按钮
- 自动分配order（按现有类别数量）
- 保存到Hive数据库
- 显示成功提示

#### ✅ 编辑类别
- 点击类别更多菜单选择"编辑"
- 或长按类别选择"编辑"
- 打开编辑对话框（预填充当前信息）
- 修改名称或颜色
- 点击"保存"按钮
- 更新数据库
- 显示成功提示

#### ✅ 删除类别
- 点击类别更多菜单选择"删除"
- 或长按类别选择"删除"
- 或在编辑对话框中点击"删除此类别"
- **检查是否有任务**：
  - 有任务：显示错误提示，无法删除
  - 无任务：显示确认对话框
- 确认后删除
- 如果删除的是当前选中类别，自动切换到"全部"
- 显示成功提示
