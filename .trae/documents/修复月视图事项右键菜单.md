## 问题复盘（为什么你现在右键没反应）
- 月视图里“待办/任务”目前来自 [schedule_screen.dart](file:///d:/Projects/SnowView/lib/presentation/screens/schedule_screen.dart#L386-L425) 构造的 `todosByDate: Map<String, List<String>>`（只有标题，没有 taskId），并且在 [widgets.dart:DayCell](file:///d:/Projects/SnowView/lib/presentation/screens/schedule/widgets.dart#L287-L292) 里直接渲染 `EventPill`，**既没有右键监听，也无法删除**。
- 你提到“月视图直接添加任务可能没有 taskID”：当前月视图双击添加的是 `AddEventDialog`（新增日程事件），确实不涉及任务清单；如果我们要在月视图“新增待办/任务”，必须在新增时同步创建一条 `ChecklistTask`，从而保证一定有 taskId。

## 目标
- 月视图右键菜单覆盖三类对象：
  1) 日程事件（CalendarEvent）：右键 pill → 菜单 → 删除。
  2) 计划中的待办/全天任务（DailyPlan 里的 taskId 列表）：右键 pill → 菜单 → 从当天移除。
  3) 空白日期格：右键日期格 → 菜单 → 新增待办/新增全天任务/新增日程事件。
- **月视图新增待办/任务时**：同时写入任务清单（未安排任务：dueDate 为空），并把该 taskId 加入当天 `DailyPlan`，这样月视图能立即显示且任务列表里也出现。

## 实现方案（结合当前项目结构）
### 1) 引入“月视图计划事项”结构（避免只有标题）
- 在 [models.dart](file:///d:/Projects/SnowView/lib/presentation/screens/schedule/models.dart) 新增：
  - `enum MonthPlanItemType { allDayTask, todoTask }`
  - `class MonthPlanItem { String taskId; String title; MonthPlanItemType type; }`

### 2) ScheduleScreen 构造月视图数据时带上 taskId + 类型
- 修改 [schedule_screen.dart](file:///d:/Projects/SnowView/lib/presentation/screens/schedule_screen.dart#L386-L425)：
  - `todosByDate` 从 `Map<String, List<String>>` 改成 `Map<String, List<MonthPlanItem>>`。
  - `plan.allDayTaskIds` → 生成 `MonthPlanItem(type: allDayTask)`
  - `plan.todoTaskIds` → 生成 `MonthPlanItem(type: todoTask)`

### 3) MonthView/DayCell 同时支持：右键删除 + 右键新建
- 修改 [month_view.dart](file:///d:/Projects/SnowView/lib/presentation/screens/schedule/month_view.dart)：
  - 接收新的 `todosByDate` 类型。
  - 新增 2 个回调：
    - `Future<void> Function(DateTime date, MonthPlanItem item) onRemovePlanItem`
    - `Future<void> Function(DateTime date, MonthPlanItemType type, String title) onCreatePlanTask`
- 修改 [widgets.dart:DayCell](file:///d:/Projects/SnowView/lib/presentation/screens/schedule/widgets.dart#L180-L303)：
  - 把 `todos: List<String>` 改为 `planItems: List<MonthPlanItem>`。
  - 为每个 pill（事件/计划事项）用 `Listener(onPointerDown)` 监听右键（`kSecondaryMouseButton`），触发 `showMenu`（更稳，不依赖 tap 手势识别）。
  - 为“空白日期格”本身也加 `Listener`：右键空白处弹出菜单（新增待办/新增全天任务/新增日程）。

### 4) 月视图“新增待办/任务”时，保证写入任务清单（产生 taskId）
- 在 `ScheduleScreen`（月视图分支）实现 `onCreatePlanTask`：
  - 弹出一个简单输入框（标题）。
  - 调用 `TaskListProvider` 新增任务并返回 taskId（需要把 `TaskListProvider.createTask` 改为返回 id，或新增 `createTaskReturningId`）。
  - **不设置 dueDate**（因此在任务列表里是“未安排任务”）。
  - 调用 `DailyPlanProvider.addTodoTask(date, taskId)` 或 `addAllDayTask(date, taskId)`。
  - 依赖现有 `DailyPlanProvider.notifyListeners()`，让 [schedule_screen.dart](file:///d:/Projects/SnowView/lib/presentation/screens/schedule_screen.dart#L103-L213) 的 FutureBuilder 重新取数并刷新月视图。

### 5) 日程事件的新建保持现状
- “新增日程事件”菜单项直接复用已有 `_openAddEventDialog(date,date)`（即现在 MonthView 的双击逻辑）。
