## 目标行为
- 月视图：对“安排事项”（月格子中的事件条目）右键 → 弹出菜单 → 选择“删除”即可删除该事项。
- 日/周视图：对“今日任务”和“今日待办”中的单条 pill 右键 → 弹出“删除”选项 → 执行后从该日计划中移除。
- 视觉与交互：适当增大事项 pill 的高度（提升命中率/可点区域），让用户更容易选择。

## 实现方案
### 1) 月视图：为事项 pill 增加右键删除
- 扩展 [MonthView](file:///d:/Projects/SnowView/lib/presentation/screens/schedule/month_view.dart) 构造参数：新增 `onDeleteEvent: Function(CalendarEvent)`（必要时也可加 `onUpdateEvent`，但本需求只做删除）。
- 在 [schedule_screen.dart](file:///d:/Projects/SnowView/lib/presentation/screens/schedule_screen.dart#L373-L435) 创建 MonthView 时把现有 `_deleteEvent` 传下去。
- 在 [DayCell/EventList](file:///d:/Projects/SnowView/lib/presentation/screens/schedule/widgets.dart#L168-L244) 中：
  - 给每个“事件”对应的 EventPill 外层包一层 `GestureDetector`/`InkWell`，实现 `onSecondaryTapDown`。
  - 右键时用 `showMenu` 弹出仅含“删除”的菜单项，选择后调用 `onDeleteEvent(event)`。
  - 覆盖范围包括：timed events（EventList 渲染）以及 allDayTasks（DayCell 顶部渲染的事项）。

### 2) 日/周视图：让“今日任务/今日待办”可右键删除
- 改造 [SingleAllDayRow/SingleTodoRow](file:///d:/Projects/SnowView/lib/presentation/screens/schedule/all_day_row.dart) 的数据输入：
  - `SingleAllDayRow` 仍接收 `List<CalendarEvent>`，但新增 `onSecondaryTapEvent: (CalendarEvent e, Offset pos) => ...` 或更直接新增 `onDeletePill: (CalendarEvent e) => ...`；行内对每个 EventPill 绑定右键菜单。
  - `SingleTodoRow` 把 `List<List<String>> todos` 改为 `List<List<TodoItem>>`（包含 `taskId` + `title`），并新增 `onDeleteTodo: (DateTime date, String taskId) => ...`。
- 在 [day_view.dart](file:///d:/Projects/SnowView/lib/presentation/screens/schedule/day_view.dart#L203-L257) 和 [week_view.dart](file:///d:/Projects/SnowView/lib/presentation/screens/schedule/week_view.dart#L285-L346) 构造这些数据时保留 taskId：
  - 今日任务：如果来自 `DailyPlanHive.allDayTaskIds` → 删除时调用 [DailyPlanProvider.removeAllDayTask](file:///d:/Projects/SnowView/lib/presentation/providers/daily_plan_provider.dart#L253-L270)。
  - 今日待办：来自 `DailyPlanHive.todoTaskIds` → 删除时调用 [DailyPlanProvider.removeTodoTask](file:///d:/Projects/SnowView/lib/presentation/providers/daily_plan_provider.dart#L236-L251)。
  - 对于“今日任务”里混入的真正日历 allDay 事件（非 taskId 的那类），删除时走现有 `onDeleteEvent`（即 schedule_screen 的 `_deleteEvent`）。
- 右键菜单交互：使用 `showMenu`（与任务列表右键菜单一致），提供一个“删除”项；执行对应 remove 方法即可。
